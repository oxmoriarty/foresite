- Optional Google Account Quota is time-limited (four days), not guaranteed, and does not remove responsibility for fees outside its quota/window.
- Judging covers technical implementation, design, potential impact, and idea quality.
- Deadline shown in the uploaded PDF: November 30, 2026, 11:00pm GMT+1.

ForeSite selects Chrome first. Runtime evidence must prove actual hybrid behavior. Do not assume every Chrome device has a ready local model or that image input is supported in every SDK/device configuration. Verify current official docs and runtime behavior.
