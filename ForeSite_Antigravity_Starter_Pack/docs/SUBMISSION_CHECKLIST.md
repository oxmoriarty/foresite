# Submission checklist

- [ ] Select Web (Chrome) on Devpost.
- [ ] Working Chrome demo.
- [ ] Firebase AI Logic imported and actually invoked at runtime.
- [ ] Hybrid inference demonstrated with genuine SDK evidence; no fabricated source labels.
- [ ] App Check configured.
- [ ] Public GitHub/GitLab repo with all source/assets/run instructions.
- [ ] Open-source license visible at repository top.
- [ ] No secrets, debug tokens, personal data, or confidential site photos committed.
- [ ] Public YouTube demo <= 3 minutes; English or English subtitles; shows the app functioning.
- [ ] Description explains Firebase AI Logic use, features, and value proposition.
- [ ] Hosted URL included if available.
- [ ] Free access confirmed; no misleading unlimited-free claims.
- [ ] Recheck live rules, current Firebase docs, model/API details, and pricing before submission.
