# ForeSite — Antigravity setup

1. Open this folder as the Antigravity workspace.
2. Install Firebase Agent Skills using the current official guide: https://firebase.google.com/docs/ai-assistance/agent-skills
3. Firebase MCP is optional development-time tooling; it is not the app's runtime AI integration.
4. Run `prompts/PHASE_0_DISCOVERY.md` first. It is explicitly read-only.
5. Review the report and approve each later phase separately.

Phase 0 must verify the current Firebase AI Logic Web hybrid SDK, exact API/model configuration, image + text support, browser/device requirements, local-first/fallback behavior, inference-source metadata, App Check, and Spark/no-billing feasibility. If any critical requirement is unverified or requires billing, stop and report it.
